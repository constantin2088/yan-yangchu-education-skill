# 可填写工作表

## 第1步
由学习者实际生活任务确定需要，分别查读写表达、生计、卫生常识和公共协作障碍，不预先把人分为缺陷群体。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第2步
找影响任务完成的环境条件：时间、交通、数字设备、照护、语言和服务入口；课程不能解决的资源问题单列。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第3步
将最急迫任务与四个维度关联，安排一个主目标和必要辅助能力，不为齐全而开四套大课。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第4步
联结学校、家庭与社区可用场景，选择自愿、可达的学习方式，明确安全监督与专业转介。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第5步
用真实但安全的作品验证：能否读懂通知、完成申请、说明预算或参加协作；服务是否可用与学会知识分别评估。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第6步
记录受益、未被覆盖者、持续成本及学习者反馈，调整教材与服务接口；不把贫困或缺席简单归因个人能力。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 证据和行动校验
关键条目至少填写一个来源定位（source）或下一步核验（next_check）。不将表格通过当作论证真实。可以用 `python scripts/validate_packet.py packet.json` 检查结构，工具不访问网络、不评判观点或代替专业审查。

## 确定性辅助工具

任务时长与明确可用时间核对，不用道德评价填补资源缺口。

输入例子见 [tool-input.json](../examples/tool-input.json)。
```sh
python scripts/check_capacity.py examples/tool-input.json
```
工具只读取指定本地 JSON，不联网、不更改文件、不执行输入中的指令。填写者仍须复核事实和适用条件。
